Zentia Launches The First PvE Server

Environment (PvE) server for their beloved, charmingly hardcore, 3D MMORPG game, Zentia. To better accommodate Zentia's growing community, the Player vs. Player (PvP) server Spoon has been converted to a PvE realm. The updated server is available to all players starting today.

"We received a lot of feedback from our growing community requesting a PvE server, so now we are very excited to present to you the first Zentia PvE server." says Susan Revelt, Zentia's Senior Producer. "To celebrate the occasion, we are providing players with over $50,000 Zentia Gold worth of prizes!"

Today, Zentia's Spoon server is being renewed expressly for PvE players. Just as with Zentia's PvP server, "Inconceivable", gamers will continue to be able to participate in different events and battle grounds, raid bosses, and unlock new content and leveling caps. The PvE Spoon server has everything players expect in a server except for the Player Killing (PK). Players can create their new avatars from any of twenty-four immortal characters with eight different class systems to begin their adventures.

In celebration of the new PvE server and Holidays, players will be randomly selected to receive 200 tokens in their inventory today. These tokens can be used to purchase items in the Zentia Token Shop. The Zentia team will also be giving out $500 Zentia Money gift cards to four lucky winners.
