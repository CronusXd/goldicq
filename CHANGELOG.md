# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2024-10-22

### Adicionado
- Documentação completa do projeto em português
- README.md com informações detalhadas
- CONTRIBUTING.md com guia de contribuição
- LICENSE com termos de uso
- .gitignore configurado para o projeto
- Estrutura inicial do repositório GitHub

### Funcionalidades Existentes
- Sistema de e-commerce para moedas virtuais de jogos
- Suporte a mais de 300 jogos online
- Sistema de login e registro de usuários
- Carrinho de compras
- Múltiplos métodos de pagamento
- Suporte multilíngue (EN, DE, FR)
- Sistema de notícias e promoções
- Chat ao vivo para suporte
- Programa VIP com descontos
- Sistema de avaliações
- Integração com Google Analytics
- Integração com Facebook
- Integração com sistemas de pagamento
